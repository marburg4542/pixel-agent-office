## 1. ฟีเจอร์ทั้งหมด

### ออฟฟิศและเอเจนต์

- **ออฟฟิศ pixel art** ห้องละ 8 โต๊ะ มีกระดานงานบนผนัง โน้ตแปะผนัง ทีวีห้องข่าว นาฬิกาและหน้าต่างที่ท้องฟ้าเปลี่ยนตามเวลาจริง
- **จ้างเอเจนต์** และแต่งตัวละครเองได้: สีผิว ทรงผม สีผม ดวงตา เสื้อ สีเสื้อ สีกางเกง เครื่องประดับ
- **บทบาท 10 แบบ:** นักวางแผน, นักค้นคว้า, นักวิเคราะห์ข่าว/โซเชียล, โปรแกรมเมอร์, นักเขียน, นักออกแบบ, ผู้ตรวจงาน, ผู้ทดสอบ, ผู้จัดการ และบทบาทกำหนดเอง
- **เลือกโมเดล AI ได้ทีละตัว** ระบบแนะนำโมเดลที่เหมาะกับบทบาทให้ และเขียน "คำสั่งประจำตัว" ให้แต่ละเอเจนต์ได้
- **เอเจนต์มีชีวิต:**
  - เดินไปหยิบงานที่กระดาน อ่านโน้ต แล้วกลับมาทำงานที่โต๊ะ
  - ส่งกระดาษต่อให้เพื่อน
  - ว่างนานๆ จะเดินไปกดน้ำหรือรดน้ำต้นไม้
  - มีไอคอนความรู้สึกเหนือหัว
- **กลางคืน** (หลัง 19:00 ตามเวลาเครื่อง): ห้องมืดลงและโคมไฟโต๊ะเปิด
- **หลายห้อง:** สูงสุด 4 ห้อง ห้องละ 8 โต๊ะ (รวม 32 เอเจนต์) สลับด้วยแท็บ
- **ธีมออฟฟิศ 2 แบบ:** ไม้อบอุ่น และโมเดิร์นสว่าง

### กระดานงานและลำดับการส่งต่อ

- **Kanban 5 คอลัมน์:** คลังงาน → รอทำ → กำลังทำ → รอตรวจ → เสร็จแล้ว ลากการ์ดย้ายคอลัมน์ได้
- **ลำดับการส่งต่อ (pipeline):** เช่น นักวางแผน → นักเขียน → ผู้ตรวจงาน ผลงานของขั้นก่อนจะถูกส่งให้ขั้นถัดไป
- **ขั้นที่ทำพร้อมกัน:** จัดกลุ่มเอเจนต์ให้ทำพร้อมกันได้ เช่น นักออกแบบกับนักเขียน แล้วค่อยส่งต่อให้ผู้ตรวจ
- **แม่แบบลำดับงาน:** โค้ด, โค้ด + ทดสอบ, บทความ, ออกแบบ, ข่าว/ความเห็น
- **ความสำคัญ** (ต่ำ/กลาง/สูง), **ขนาดงาน** (เล็ก/กลาง/ใหญ่) และตัวเลือก "ส่งให้ตรวจก่อนปิดงาน"
- **ผลงานเป็น Markdown:** คัดลอกหรือดาวน์โหลดเป็นไฟล์ .md ได้ทีละขั้นหรือทั้งหมด
- **ลบงานหรือโน้ตแล้วกด "เลิกทำ" ได้**
- **กระดานเปิดเป็นหน้าต่างใหญ่** และมีช่อง "เพิ่มด่วน" ท้ายคอลัมน์

### โน้ต

- **แปะโน้ตถึงเอเจนต์คนเดียวหรือทุกคน** เลือกสีได้ และผูกกับงานที่ต้องการได้
- **เอเจนต์จะเดินมาอ่าน** (หรืออ่านระหว่างทำงาน) แล้วนำไปใช้ในผลงาน และแสดงให้เห็นว่าใครอ่านแล้ว

### AI จริงและค่าใช้จ่าย

- **ผู้ให้บริการที่รองรับ:** Anthropic (Claude), OpenAI, Google (Gemini), OpenRouter และ Ollama ที่รันในเครื่อง
- **ใช้ API key ของแต่ละคนเอง** เก็บบนเซิร์ฟเวอร์แบบเข้ารหัส และแสดงให้เห็นแค่ตัวท้ายของคีย์
- **หน้า "ตั้งค่า AI" รวมทุกอย่างไว้ที่เดียว:** ใส่คีย์ → ทดสอบ → ดึงรายชื่อโมเดลจริงจากผู้ให้บริการมาติ๊กเพิ่มได้เลย ไม่ต้องพิมพ์ชื่อรุ่นเอง
- **Ollama:** ตรวจหาโมเดลที่ติดตั้งในเครื่องให้อัตโนมัติ และตั้งความยาว context ของแต่ละโมเดลได้
- **ดูคำตอบไหลเข้ามาสด** ระหว่างที่โมเดลกำลังเขียน
- **โหมดจำลอง:** เอเจนต์ที่ไม่มีคีย์ทำงานแบบจำลองฟรี ป้ายมุมบนบอกสถานะว่าเป็น AI จริง / AI + จำลอง / โหมดจำลอง
- **ตั้งงบรายเดือนได้** ถึงงบแล้วระบบเปลี่ยนเป็นการจำลองให้ และมีสรุปค่าใช้จ่ายรายโมเดล
- **เมื่อเรียก AI ไม่สำเร็จ** งานขึ้น ⛔ พร้อมเหตุผลและวิธีแก้
  - ติด rate limit หรือติดต่อไม่ได้: ระบบลองใหม่เอง
  - คีย์ผิดหรือเครดิตหมด: รอให้คุณกด "ลองใหม่"
- **ค้นเว็บเอง:** นักค้นคว้าและนักวิเคราะห์ใช้การค้นเว็บของโมเดลได้ ถ้าผู้ให้บริการรองรับ

### ทำงานร่วมกัน

- **เอเจนต์ถามกลับ:** ถ้าโจทย์ไม่ชัด เอเจนต์จะหยุดถามและรอคำตอบ (❓)
- **ผู้ตรวจงานส่งกลับเอง:** ส่งกลับไปให้ขั้นที่ควรแก้พร้อมความเห็นได้สูงสุด 2 รอบ จากนั้นงานมารอคุณตรวจ
- **ผู้จัดการ (manager):** วางลำดับเอเจนต์ให้เองกับงานที่ยังไม่ได้เลือกใครทำ
- **Model Arena:** ให้ 2–4 โมเดลทำขั้นเดียวกันแล้วเทียบผล (ซ่อนชื่อได้) เลือกผู้ชนะ และสะสมเป็นตารางคะแนน

### ห้องข่าวและกระแสโซเชียล

- **งานวิจัยข่าว:** เอเจนต์เก็บข่าว โพสต์โซเชียล และตัวเลขตลาด แล้ววิเคราะห์ความรู้สึก/ทัศนคติต่อแบรนด์ สินค้า บริการ หรือประเด็น ออกเป็นรายงานพร้อมกราฟ
- **ห้องข่าว (Newsroom):** รายการติดตามที่รันอัตโนมัติ (กดเอง / ทุก 6 ชม. / ทุกวัน / ทุกสัปดาห์) เก็บประวัติรายงานและมีกราฟแนวโน้มความรู้สึก
- **แหล่งข้อมูล:**
  - ข่าว: GDELT (รวมข่าวไทย), Google News (ไทย/อังกฤษ)
  - โซเชียล: Hacker News, Reddit, YouTube, Bluesky
  - ตลาด: Finnhub, Alpha Vantage (หุ้น), CoinGecko, Crypto Fear & Greed (คริปโต)
  - การค้นเว็บของโมเดล

### สถิติ

- **ผลงาน:** จำนวนขั้นที่ทำเสร็จ, เวลาเฉลี่ยต่อขั้น และจำนวนครั้งที่ถูกส่งกลับ แยกตามเอเจนต์และโมเดล
- **คุณภาพ:** อัตราผ่านตั้งแต่รอบแรก
- **ค่าใช้จ่าย:** ค่าใช้จ่ายรายวันย้อนหลัง 30 วัน
- **ภาพรวม:** ตารางคะแนน Arena, ภาพรวมงานส่วนรวมของทีม และบรรยากาศข่าวของทุกรายการติดตาม

### บัญชีผู้ใช้และทีม

- **สมัครแล้วรออนุมัติ:** สมัครสมาชิก → รอแอดมินอนุมัติ → ได้ออฟฟิศของตัวเองพร้อมทีมตัวอย่าง
- **ลืมรหัสผ่าน:** รับลิงก์รีเซ็ตทางอีเมล (หมดอายุ 30 นาที ใช้ได้ครั้งเดียว)
- **ความปลอดภัย:** มีกติการหัสผ่าน จำกัดการเดารหัส และ 1 บัญชีใช้ได้ทีละอุปกรณ์
- **งานส่วนตัว / งานส่วนรวม:** งานส่วนรวมทุกคนในทีมเห็น และแต่ละคนนำเอเจนต์ของตัวเองมาร่วมทำได้
- **แอดมิน:** อนุมัติ, ปฏิเสธ, ระงับ, คืนสิทธิ์ หรือลบผู้ใช้ และกำหนดบทบาทได้

### ตั้งค่าส่วนตัว

- **โปรไฟล์:** รูป, ชื่อผู้ใช้, อีเมล, รหัสผ่าน
- **เสียงและภาษา:** เสียงเกม, ระดับเสียง, ภาษาไทย/อังกฤษ, ธีมออฟฟิศ, แจ้งเตือนเดสก์ท็อป
- **คีย์แหล่งข้อมูล:** คีย์ของแหล่งข้อมูลข่าว/หุ้น/โซเชียล พร้อมปุ่มทดสอบ (คีย์ของโมเดล AI อยู่ที่หน้า **ตั้งค่า AI**)
- **ข้อมูล:** สำรอง กู้คืน หรือเริ่มออฟฟิศใหม่

### มือถือและแท็บเล็ต (ติดตั้งเป็นแอปได้)

- **ติดตั้งลงเครื่องได้ (PWA):** มีไอคอนบนหน้าจอหลัก เปิดเต็มจอเหมือนแอป
- **ใช้ในแนวนอนเท่านั้น:** หน้าตาเหมือน laptop แบบกระชับ ถ้าถือแนวตั้งจะขึ้นหน้าให้หมุนเครื่อง
- **หน้าต่างเปิดเต็มจอ** บนจอเตี้ย

## 2. ตั้งค่าก่อนเริ่มใช้งาน

### 2.1 สิ่งที่ต้องมี

- **Node.js 22 ขึ้นไป** (ทดสอบกับ 22.15) และ npm
- **เครื่องที่จะรันเซิร์ฟเวอร์:** เซิร์ฟเวอร์ต้องเปิดไว้ตลอด เพราะเอเจนต์ทำงานบนเซิร์ฟเวอร์ แม้ไม่มีใครเปิดหน้าเว็บ
- **(ไม่บังคับ) บัญชีอีเมล** สำหรับส่งลิงก์ลืมรหัสผ่านและแจ้งผลอนุมัติ เช่น Gmail + App Password
- **(ไม่บังคับ) API key** ของผู้ให้บริการ AI ถ้าไม่มี ทุกอย่างจะทำงานแบบจำลอง

### 2.2 ติดตั้ง

เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่งตามลำดับ

```bash
npm install
```

```bash
npm run setup
```

`npm run setup` จะสร้างไฟล์ `server/.env` และสุ่มรหัสลับให้อัตโนมัติ (`JWT_SECRET`, `ENCRYPTION_KEY`) จากนั้นจะ**แสดงชื่อผู้ใช้และรหัสผ่านของแอดมินคนแรกบนหน้าจอ** ให้จดไว้ แล้วเปลี่ยนรหัสผ่านหลังล็อกอินครั้งแรก

### 2.3 ค่าในไฟล์ `server/.env`

| ค่า | ใช้ทำอะไร | ต้องแก้เองไหม |
|---|---|---|
| `PORT` | พอร์ตของเซิร์ฟเวอร์ (ค่าเริ่มต้น 5200) | ไม่ต้อง |
| `JWT_SECRET` | รหัสลับสำหรับการล็อกอิน (สร้างให้แล้ว) — ถ้าเปลี่ยน ทุกคนต้องล็อกอินใหม่ | ไม่ต้อง |
| `ENCRYPTION_KEY` | กุญแจเข้ารหัส API key ของผู้ใช้ (สร้างให้แล้ว) — ⚠️ **ห้ามเปลี่ยนหรือทำหาย** ไม่อย่างนั้นคีย์ที่ทุกคนบันทึกไว้จะใช้ไม่ได้ ควรสำรองไฟล์นี้ไว้ | ไม่ต้อง |
| `DB_FILE` | ไฟล์ฐานข้อมูล SQLite | ไม่ต้อง |
| `FRONTEND_URL` | ที่อยู่หน้าเว็บที่อนุญาต และใช้เป็นฐานของลิงก์ในอีเมล ใส่ได้หลายค่าคั่นด้วยจุลภาค (ใส่โดเมนที่ใช้จริงไว้ตัวแรก) | ถ้าใช้งานผ่านโดเมนจริง |
| `BOOTSTRAP_ADMIN_USERNAME` / `_EMAIL` / `_PASSWORD` | แอดมินคนแรก สร้างครั้งเดียวตอนเปิดเซิร์ฟเวอร์ครั้งแรก | แก้อีเมลให้เป็นของจริง |
| `EMAIL_*` | การส่งอีเมล (ดูข้อ 2.4) | ถ้าต้องการให้ส่งอีเมลได้ |

> ห้าม commit หรือแชร์ไฟล์ `server/.env` (อยู่ใน `.gitignore` แล้ว)

### 2.4 ตั้งค่าอีเมล (ไม่บังคับ แต่แนะนำ)

ถ้าไม่ตั้ง ระบบยังใช้ได้ทุกอย่าง แต่จะส่งลิงก์ลืมรหัสผ่านและอีเมลแจ้งอนุมัติไม่ได้ (ตอนอนุมัติ ระบบจะเตือนให้แจ้งผู้ใช้เอง)

- **Gmail:** เว้น `EMAIL_HOST` ว่างไว้ แล้วใส่ `EMAIL_USER` (อีเมล Gmail) กับ `EMAIL_PASS` (App Password สร้างได้ที่ myaccount.google.com/apppasswords)
- **SMTP อื่นๆ:** ใส่ `EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_SECURE`, `EMAIL_USER`, `EMAIL_PASS`
- `EMAIL_FROM` คือชื่อหรืออีเมลผู้ส่ง (ไม่บังคับ)

### 2.5 เปิดใช้งาน

**แบบพัฒนา/ทดลองในเครื่อง** — เปิดทั้งหน้าเว็บและเซิร์ฟเวอร์พร้อมกัน:

```bash
npm run dev:all
```

แล้วเปิด http://localhost:5173

**แบบใช้งานจริง** — build หน้าเว็บ แล้วให้เซิร์ฟเวอร์เสิร์ฟทั้งหน้าเว็บและ API ที่ที่อยู่เดียว:

```bash
npm run build
```

```bash
npm start
```

แล้วเปิด http://localhost:5200 ถ้าจะเปิดให้คนอื่นเข้าจากภายนอก ให้ชี้ Cloudflare Tunnel มาที่ `http://localhost:5200` และใส่โดเมนนั้นไว้เป็นค่าแรกของ `FRONTEND_URL` (ถ้าต้องการให้เปิดเองอัตโนมัติ ใช้ pm2 ได้)

> หมายเหตุ: ขั้นตอน deploy ขึ้นโดเมนจริงยังไม่ได้ตั้งค่าในโปรเจกต์นี้ ส่วนเว็บบน GitHub Pages ใช้ได้เฉพาะเวอร์ชันจำลองแบบเก่า

### 2.6 สิ่งที่ควรทำหลังล็อกอินครั้งแรก (ในฐานะแอดมิน)

1. **เปลี่ยนรหัสผ่านแอดมิน:** ตั้งค่า → โปรไฟล์
2. **เปิดหน้า ตั้งค่า AI** (ปุ่มบนแถบบน หรือกดป้ายสถานะ AI มุมซ้ายบน) แล้วทำตามนี้กับผู้ให้บริการที่จะใช้ (ดูตารางข้อ 2.7) — ทุกคนใส่คีย์ของตัวเองได้
   - กด **ใส่ key** → วางคีย์ → **บันทึก** ระบบจะทดสอบคีย์และดึงรายชื่อโมเดลที่คีย์นั้นใช้ได้มาให้ทันที
   - **ติ๊กโมเดลที่ต้องการ** แล้วกด **เพิ่ม** — ไม่ต้องพิมพ์ API model ID เอง (กด **เลือกโมเดล** เพื่อเปิดรายการอีกครั้งภายหลัง)
   - โมเดลที่ขึ้นป้าย **ไม่มีราคา**: ใส่ราคาต่อ 1 ล้านโทเคน (เข้า/ออก) ใน 🧠 คลังโมเดล เพราะใช้คำนวณค่าใช้จ่ายและงบรายเดือน (OpenRouter และโมเดลที่แอปรู้จักใส่ราคาให้แล้ว)
   - **Ollama:** ใส่ที่อยู่เซิร์ฟเวอร์ (ปกติ `http://localhost:11434`) แล้วระบบจะตรวจหาโมเดลที่ติดตั้งไว้ให้เอง ตั้ง **Context** ของแต่ละโมเดลได้ (ค่าเริ่มต้น 8K ยิ่งยาวยิ่งรับบรีฟ/ข้อมูลค้นคว้าได้มาก แต่ใช้หน่วยความจำมากขึ้น การ์ดจอ 4 GB แนะนำ 8K–16K)
3. **ตรวจคลังโมเดล (🧠 คลังโมเดล — ปุ่มมุมซ้ายล่างของหน้า ตั้งค่า AI)** ถ้าต้องการปรับชื่อ ความเร็ว/คุณภาพ (ใช้กับการจำลอง) หรือราคา ส่วนโมเดลตัวอย่างที่ติดมากับแอปให้ตรวจว่าชื่อรุ่นยังตรงกับของผู้ให้บริการ
4. **ตั้งงบ:** หน้า ตั้งค่า AI → งบต่อเดือน (USD) ถ้าต้องการจำกัดค่าใช้จ่าย (0 = ไม่จำกัด)
5. **(ไม่บังคับ) แจ้งเตือนเดสก์ท็อป:** ตั้งค่า → เสียงและภาษา → แจ้งเตือนบนเดสก์ท็อป เพื่อรับแจ้งเตือนเมื่อมีงานรอตรวจหรือเอเจนต์มีคำถาม

## 3. วิธีการใช้งาน

### 3.1 เริ่มต้น

1. **สมัครสมาชิก:** ไปที่หน้าเข้าสู่ระบบ → "สมัครสมาชิก" แล้วรอแอดมินอนุมัติ (ถ้าตั้งค่าอีเมลไว้จะได้อีเมลแจ้ง)
2. **เข้าสู่ระบบ:** จะได้ออฟฟิศของตัวเองพร้อมทีมตัวอย่าง 5 คน (Nova, Byte, Pixel, Quill, Sage) และงานตัวอย่าง
3. **ทัวร์แนะนำ:** ครั้งแรกจะมีทัวร์แนะนำ เปิดดูใหม่ได้ทุกเมื่อจากปุ่ม **?**

### 3.2 รู้จักหน้าจอ

- **แถบบน:**
  - ป้ายสถานะ AI (กดเพื่อเปิดหน้า ตั้งค่า AI), หยุด/เล่น และความเร็ว ×1–×8
  - ตัวเลขสรุป: จำนวนเอเจนต์/โต๊ะ, งานรอทำ, กำลังทำ, รอตรวจ, คำถาม
  - ปุ่มเปิดหน้าต่างต่างๆ
- **ออฟฟิศ:**
  - คลิก **กระดานบนผนัง** เปิดกระดานงาน
  - คลิก **ทีวีใต้นาฬิกา** เปิดห้องข่าว
  - คลิก **เอเจนต์** ดูโปรไฟล์
  - คลิก **โต๊ะว่าง** จ้างเอเจนต์
  - คลิก **โน้ตบนผนัง** เปิดโน้ต
- **แถบข้าง:** รายชื่อทีมและกิจกรรมล่าสุด (บนจอแคบกดปุ่มทีมเพื่อเปิด)
- **ความเร็วและการหยุด:** มีผลกับงานจำลอง ส่วนงานที่กำลังเรียก AI จริงจะทำต่อจนเสร็จ

### 3.3 จ้างและแต่งเอเจนต์

1. คลิกโต๊ะว่าง หรือกด **➕ จ้างเอเจนต์**
2. แท็บ **หน้าตา**: แต่งตัวละคร (มีปุ่ม 🎲 สุ่ม)
3. แท็บ **หน้าที่**: ตั้งชื่อ เลือกบทบาท เลือกโมเดล (มีตัวแนะนำตามบทบาท) และเขียนคำสั่งประจำตัว เช่น "เขียนสั้น กระชับ ใช้ภาษาเป็นกันเอง"
4. ถ้ามีหลายห้อง เลือกห้องและโต๊ะได้
5. แก้ไขเอเจนต์ภายหลังได้จากหน้าโปรไฟล์ (คลิกที่ตัวเอเจนต์)

### 3.4 สร้างงานและลำดับการส่งต่อ

1. เปิดกระดาน → **＋ งานใหม่** (หรือกด `N`)
2. ใส่ชื่องานและรายละเอียด (ยิ่งละเอียด เอเจนต์ยิ่งถามกลับน้อย)
3. เลือก **ส่วนตัว / ส่วนรวม**, ความสำคัญ, ขนาดงาน (ใหญ่ = ใช้เวลาและความยาวคำตอบได้มากขึ้น) และคอลัมน์ที่จะวางไว้
4. **ลำดับการส่งต่อ**: คลิกเอเจนต์เพื่อเพิ่มเป็นขั้น หรือใช้ **แม่แบบ** เรียงลำดับได้ด้วย ▲▼
5. **ทำพร้อมกัน**: กดปุ่ม **⇉** ที่ขั้นใด ขั้นนั้นจะทำพร้อมกับขั้นข้างบน งานจะไปต่อเมื่อทุกคนในกลุ่มทำเสร็จ
6. ติ๊ก **ส่งให้ตรวจก่อนปิดงาน** ถ้าต้องการตรวจงานก่อนปิด
7. ถ้าไม่เลือกเอเจนต์เลยและมี **ผู้จัดการ** ผู้จัดการจะวางลำดับให้เอง (ข้อ 3.10)

งานในคอลัมน์ **รอทำ** จะถูกเอเจนต์เดินมาหยิบเอง ส่วนงานใน **คลังงาน** จะถูกพักไว้ เอเจนต์ไม่แตะ

### 3.5 ติดตามงาน

คลิกการ์ดงานเพื่อดูรายละเอียด:

- **ความคืบหน้า:** ดูได้ทีละขั้น ถ้าใช้ AI จริงจะเห็นข้อความที่เอเจนต์กำลังเขียนไหลเข้ามาสด
- **ผลงาน:** แต่ละขั้นมีปุ่มคัดลอก / ดาวน์โหลด .md และปุ่ม "ดาวน์โหลดผลลัพธ์ทั้งหมด"
- **ย้ายและเริ่มใหม่:** เลือกคอลัมน์ได้จากเมนู "ย้ายไป" หรือ "เริ่มใหม่จากขั้นแรก"
- **⛔ ติดปัญหา:** อ่านเหตุผลและวิธีแก้ แล้วกด "ลองใหม่ตอนนี้" (ถ้าติด rate limit ระบบจะลองใหม่เองตามเวลาที่แสดง)
- **บันทึกกิจกรรม:** ดูได้ว่าใครทำอะไรเมื่อไร

### 3.6 ตรวจงาน

เมื่อทุกขั้นเสร็จ งานจะไปอยู่ **รอตรวจ** (ตัวเลขบนแท็บเบราว์เซอร์และแถบบนจะแจ้งเตือน):

- **✓ อนุมัติ:** ย้ายงานไปเสร็จแล้ว
- **✎ ขอให้แก้:** เขียนสิ่งที่อยากให้แก้ แล้วเลือกเอเจนต์ที่จะทำใหม่ งานจะย้อนกลับไปขั้นนั้น (ถ้าขั้นนั้นอยู่ในกลุ่มทำพร้อมกัน ทั้งกลุ่มจะทำใหม่)
- **ผู้ตรวจงานส่งกลับเอง:** ถ้าในลำดับมีผู้ตรวจงาน เขาอาจส่งงานกลับไปแก้เองก่อน (สูงสุด 2 รอบต่องาน)

### 3.7 ตอบคำถามของเอเจนต์

เมื่อเอเจนต์ไม่แน่ใจ งานจะขึ้น ❓ บนกระดาน (และในรายการ "รอคุณอยู่" บนมือถือ)

1. เปิดงานนั้น
2. พิมพ์คำตอบในกล่องคำถาม แล้วกด "ส่งคำตอบ" (หรือ Ctrl+Enter)
3. เอเจนต์จะกลับมาทำต่อโดยใช้คำตอบนั้น

ทุกคนที่เห็นงานตอบได้ คำถามและคำตอบเก่าดูได้ในหัวข้อ "คำถามและคำตอบ"

### 3.8 โน้ต

1. กด **📝 โน้ต** บนกระดาน (หรือกด `M`)
2. เลือกผู้รับ (เอเจนต์คนเดียวหรือทุกคน), สี และผูกกับงานได้
3. เอเจนต์จะเดินมาอ่านแล้วนำไปใช้ในผลงาน ดูได้ว่าใครอ่านแล้ว

โน้ตส่วนตัวถึงได้เฉพาะเอเจนต์ของคุณ ส่วนโน้ตส่วนรวมถึงเอเจนต์ของทุกคนได้

### 3.9 ทำงานเป็นทีม (งานส่วนรวม)

- **ใครเห็น:** ตั้งงานเป็น **ส่วนรวม** แล้วทุกคนในทีมจะเห็นงานนั้น
- **ใครทำ:** แต่ละคน**เพิ่มได้เฉพาะเอเจนต์ของตัวเอง**เข้าไปในลำดับ ขั้นของใครก็ทำในออฟฟิศของคนนั้นและใช้ API key ของคนนั้น
- **เปลี่ยนส่วนตัว/ส่วนรวม:** ทำได้เฉพาะเจ้าของงาน
- **กรองงาน:** แท็บ ทั้งหมด / ส่วนตัว / ส่วนรวม บนกระดาน

### 3.10 ผู้จัดการ (manager)

1. จ้างเอเจนต์บทบาท **ผู้จัดการ**
2. สร้างงานใน **รอทำ** โดยไม่ต้องเลือกเอเจนต์
3. ผู้จัดการจะเดินมาที่กระดาน อ่านโจทย์ แล้ววางลำดับเอเจนต์ให้ (รวมถึงจัดกลุ่มที่ทำพร้อมกันได้) และเขียนเหตุผลไว้ในบันทึกกิจกรรม
4. แก้ลำดับที่ผู้จัดการวางไว้ได้ทุกเมื่อ

ผู้จัดการจัดการเฉพาะงานของเจ้าของตัวเอง ถ้าไม่มี API key จะวางลำดับจากแม่แบบตามคำในโจทย์

### 3.11 Model Arena (เทียบโมเดล)

1. เปิดงาน → ที่ขั้นที่มีผลงานแล้ว กด **⚔️ Arena**
2. เลือก 2–4 โมเดล และเลือก "ซ่อนชื่อโมเดลจนกว่าจะเลือก" ถ้าต้องการ แล้วกด **เริ่ม**
3. อ่านคำตอบที่เรียงเคียงกัน แล้วกด **🏆 เลือกอันนี้**
4. ติ๊ก "ใช้ผลที่ชนะเป็นผลงานของขั้นนี้" ถ้าจะเอาคำตอบนั้นไปใช้

ข้อควรรู้:
- ใช้คีย์และคลังโมเดลของคนที่กด Arena โมเดลที่ไม่มีคีย์จะตอบแบบจำลอง
- ขั้นถัดไปที่ทำไปแล้วจะไม่ถูกทำใหม่ให้อัตโนมัติ ถ้าต้องการให้ใช้เวอร์ชันใหม่ ให้เริ่มใหม่จากขั้นนั้น
- ผลการเลือกสะสมในตารางคะแนนในหน้าสถิติ

### 3.12 งานวิจัยข่าวและห้องข่าว

**งานวิจัยครั้งเดียว**

1. สร้างงาน → ติ๊ก **📰 รวบรวมข่าวและข้อมูลโซเชียลสำหรับงานนี้** (หรือใช้แม่แบบ 📈 ข่าว/ความเห็น)
2. ใส่หัวข้อ/แบรนด์/ประเด็น, ชื่อหุ้น (เช่น AAPL), เหรียญ (เช่น bitcoin), ภาษา, ระยะเวลาย้อนหลัง และเลือกแหล่งข้อมูล
3. ขั้นของนักวิเคราะห์ (ถ้าไม่มี ใช้ขั้นแรก) จะเก็บข้อมูล แล้วเขียนรายงานพร้อมกราฟ:
   - ความรู้สึกโดยรวม
   - แยกตามแหล่งข้อมูล
   - ประเด็นหลัก
   - ราคา
   - โทนข่าว
   - จำนวนการพูดถึงต่อวัน
   - ข่าวล่าสุด
   - เสียงจากผู้คน

ทุกกราฟกดปุ่ม "ตาราง" เพื่อดูเป็นตัวเลขได้ ถ้าไม่มี API key ของโมเดล รายงานยังมีข้อมูลจริง แต่ค่าความรู้สึกเป็นค่าประมาณจากรายการคำ (มีป้ายบอก)

**ติดตามต่อเนื่อง (ห้องข่าว)**

1. กด **📺 ห้องข่าว** (หรือคลิกทีวีในออฟฟิศ) → **＋ รายการติดตามใหม่**
2. ตั้งชื่อ, เลือกส่วนตัว/ส่วนรวม, เลือกเอเจนต์ผู้ทำ (แนะนำนักวิเคราะห์ข่าว), ใส่หัวข้อและแหล่งข้อมูล
3. เลือกรอบการรัน: เฉพาะตอนกดรัน / ทุก 6 ชั่วโมง / ทุกวัน / ทุกสัปดาห์ (ตามเวลาเครื่องเซิร์ฟเวอร์)
4. กด **▶ รันเลย** เพื่อรันครั้งแรก เอเจนต์จะเดินไปทำงานบนฉาก เสร็จแล้วรายงานจะเข้าห้องข่าว
5. ดูรายงานย้อนหลังได้จากเมนู "รายงาน" และดูกราฟ "ความรู้สึกตามช่วงเวลา"

ทุกรอบที่ใช้ AI จริงจะคิดเงินกับคีย์ของเจ้าของรายการ และนับในงบรายเดือน

### 3.13 สถิติ

กด **📊 สถิติ** เพื่อดู:
- ผลงานรายเอเจนต์และรายโมเดล
- เวลาเฉลี่ยต่อขั้น และอัตราผ่านรอบแรก
- ค่าใช้จ่ายรายวัน 30 วัน
- ตารางคะแนน Arena
- ภาพรวมงานส่วนรวม
- บรรยากาศข่าว

ค่าใช้จ่ายของเพื่อนร่วมทีมจะไม่แสดงให้คนอื่นเห็น

### 3.14 หลายห้องและธีม

- **เพิ่มห้อง:** กด **＋** ที่แท็บห้องเหนือออฟฟิศ (สูงสุด 4 ห้อง)
- **เปลี่ยนชื่อห้อง:** ดับเบิลคลิกที่ชื่อห้อง
- **ลบห้อง:** กด ✕ ได้เฉพาะห้องสุดท้ายที่ไม่มีเอเจนต์
- **จ้างเอเจนต์ในห้อง:** สลับไปที่ห้องนั้นแล้วคลิกโต๊ะว่าง หรือเลือกห้องในหน้าจ้างเอเจนต์ เอเจนต์ต่างห้องส่งงานต่อกันได้ตามปกติ
- **ธีม:** ตั้งค่า → เสียงและภาษา → **หน้าตาออฟฟิศ** (ไม้อบอุ่น / โมเดิร์นสว่าง)

### 3.15 ใช้งานบนมือถือ / แท็บเล็ต

**ติดตั้งเป็นแอป** (เปิดเว็บแล้วผ่านด่านอีเมลก่อน):

- **Android (Chrome):** เมนู ⋮ → **ติดตั้งแอป** (หรือ เพิ่มลงในหน้าจอหลัก)
- **iPhone / iPad (Safari):** ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

**การใช้งาน:**

- **แนวนอนเท่านั้น:** Android ล็อกจอแนวนอนให้เมื่อเปิดจากแอปที่ติดตั้ง ส่วน iPhone/iPad ล็อกจอให้ไม่ได้ ถ้าถือแนวตั้งจะขึ้นหน้า "หมุนเครื่องเป็นแนวนอน"
- **หน้าตาเหมือน laptop แบบกระชับ:** แถบบนแถวเดียวเป็นไอคอน, ปุ่มความเร็วกดวน ×1→×8, รายชื่อทีมเปิดจากปุ่มทีม, หน้าต่างเปิดเต็มจอ
- **ด่าน Cloudflare:** แอปที่ติดตั้งจะขอรหัสทางอีเมลอีกครั้งเมื่อ session ของด่านหมดอายุ

### 3.16 สำรอง / กู้คืน / เริ่มใหม่

ไปที่ ตั้งค่า → ข้อมูล:

- **ดาวน์โหลดไฟล์สำรอง** (.json): เก็บเอเจนต์ คลังโมเดล งานพร้อมผลลัพธ์ และโน้ต
- **เลือกไฟล์สำรอง** (นำเข้า): เพิ่มเข้าไปในออฟฟิศเดิมโดยไม่เขียนทับ เอเจนต์จะเข้ามาได้เท่าที่มีโต๊ะว่าง
- **รีเซ็ตออฟฟิศของฉัน**: ลบเอเจนต์ งาน และโน้ตของคุณ แล้วได้ทีมตัวอย่างกลับมา (ควรดาวน์โหลดไฟล์สำรองก่อน)

### 3.17 แอดมิน: จัดการผู้ใช้

กด **👑 จัดการผู้ใช้** (มีตัวเลขบอกจำนวนคนที่รออนุมัติ):

- **อนุมัติ / ปฏิเสธ** ผู้สมัครใหม่
- **ระงับ / คืนสิทธิ์** ผู้ใช้
- **เปลี่ยนบทบาท** (แอดมิน/สมาชิก)
- **ลบผู้ใช้** (ลบออฟฟิศของคนนั้นทั้งหมด ย้อนกลับไม่ได้)

## 4. แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| เอเจนต์ทำงาน "แบบจำลอง" ทั้งที่ใส่คีย์แล้ว | ตรวจว่าเปิด **ใช้ AI จริง** อยู่ (หน้า ตั้งค่า AI), คีย์ตรงกับผู้ให้บริการของโมเดลที่เอเจนต์ใช้ (การ์ดผู้ให้บริการบอกว่าเอเจนต์ตัวไหนใช้อยู่) และยังไม่ถึงงบรายเดือน วางเมาส์บนป้ายสถานะมุมซ้ายบนเพื่อดูว่าเอเจนต์ตัวไหนยังจำลองอยู่ |
| งานขึ้น ⛔ "API key ถูกปฏิเสธ" | กดปุ่ม **ตั้งค่า AI** ในกล่อง ⛔ → กดทดสอบคีย์ แก้คีย์ แล้วกด "ลองใหม่ตอนนี้" |
| งานขึ้น ⛔ "ไม่พบโมเดลนี้" | หน้า ตั้งค่า AI → **เลือกโมเดล** เพื่อดูชื่อรุ่นที่คีย์ใช้ได้จริง เพิ่มรุ่นที่ถูกต้องแล้วเปลี่ยนโมเดลของเอเจนต์ (หรือแก้ API model ID ในคลังโมเดล) |
| Ollama ขึ้น "Can't reach Ollama" | Ollama ยังไม่ได้เปิด หรือที่อยู่เซิร์ฟเวอร์ไม่ตรง เปิด Ollama แล้วกด **ตรวจหาโมเดลที่ติดตั้ง** อีกครั้ง |
| Ollama ตอบช้ามาก | โมเดลใหญ่เกินการ์ดจอ (ล้นไปใช้ RAM) — ใช้รุ่น 3–4B หรือลด Context ลง |
| งานไม่ขยับเลย | ดูว่าออฟฟิศถูก **หยุด** อยู่ไหม, งานอยู่ใน "รอทำ" (ไม่ใช่คลังงาน), มีเอเจนต์ในลำดับ และไม่ได้รอคำตอบ (❓) |
| ไม่ได้รับอีเมลลืมรหัสผ่าน | ยังไม่ได้ตั้งค่า `EMAIL_*` ใน `server/.env` หรือ App Password ไม่ถูกต้อง |
| หน้าเว็บขึ้น "ติดต่อเซิร์ฟเวอร์ไม่ได้" | เซิร์ฟเวอร์ปิดอยู่หรือกำลังรีสตาร์ท หน้าเว็บจะลองเชื่อมต่อใหม่เองทุก 4 วินาที |
| ถูกออกจากระบบเอง | บัญชีเดียวใช้ได้ทีละอุปกรณ์ ถ้าเข้าสู่ระบบที่อื่น เครื่องเดิมจะถูกออก |
| ห้องข่าวบอก "GDELT is busy" | GDELT จำกัดจำนวนคำขอ ระบบเว้นจังหวะให้แล้ว ลองใหม่ภายหลัง แหล่งอื่นยังทำงานตามปกติ |
| คีย์ที่บันทึกไว้ใช้ไม่ได้ทั้งหมดหลังย้ายเครื่อง | `ENCRYPTION_KEY` ใน `server/.env` เปลี่ยนไป ให้ใช้ค่าเดิม (จึงควรสำรองไฟล์ `.env` ไว้) |

> **ข้อควรทราบ:** ฟีด Google News อนุญาตเฉพาะการใช้งานส่วนตัวที่ไม่ใช่เชิงพาณิชย์ ถ้าจะใช้เชิงธุรกิจ ให้ปิดแหล่งนี้ในรายการแหล่งข้อมูล
