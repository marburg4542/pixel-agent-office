# Pixel Agent Office

ออฟฟิศ pixel art มุมมอง isometric (3 มิติแบบเฉียง) สำหรับทีม AI agents: จ้างเอเจนต์ แต่งตัวละคร เลือกโมเดลให้เหมาะกับหน้าที่ มอบหมายงานแบบส่งต่อกันเป็นทอดๆ แปะโน้ตสื่อสารกับเอเจนต์ และทำงานร่วมกันเป็นทีม (งานส่วนตัว / ส่วนรวม)

📖 **คู่มือการใช้งานฉบับเต็ม** (ฟีเจอร์ทั้งหมด, การตั้งค่าก่อนเริ่มใช้งาน, วิธีใช้ทีละขั้น, แก้ปัญหา): [docs/USER_GUIDE.md](docs/USER_GUIDE.md)

## ส่วนประกอบ

- **หน้าเว็บ** (`src/`) — React + TypeScript + Vite วาดออฟฟิศ isometric ด้วย canvas (ฉาก 640×360 พิกเซล ขยายตามจอ)
- **เซิร์ฟเวอร์** (`server/`) — Express + SQLite (แบบเดียวกับโปรเจค WMS): บัญชีผู้ใช้, ข้อมูลออฟฟิศ, API key (เข้ารหัส), และ **worker** ที่ให้เอเจนต์ทำงานบนเซิร์ฟเวอร์ตลอดเวลา แม้ไม่มีใครเปิดหน้าเว็บ
- **โค้ดร่วม** (`shared/`) — types, คลังโมเดล, กติการหัสผ่าน, ข้อความ TH/EN ที่ทั้งสองฝั่งใช้

## วิธีรัน (ในเครื่อง)

```bash
npm install
npm run setup
npm run dev:all
```

- `npm run setup` สร้าง `server/.env` พร้อมสุ่มรหัสลับ และ**แสดงชื่อ/รหัสผ่านแอดมินคนแรก** ในหน้าจอ (จดไว้ แล้วเปลี่ยนในหน้าตั้งค่าหลังล็อกอิน)
- ตั้งค่า `EMAIL_*` ใน `server/.env` เพื่อให้ส่งอีเมลลืมรหัสผ่าน/แจ้งอนุมัติได้ (Gmail App Password หรือ SMTP)
- เปิด http://localhost:5173 (หน้าเว็บ) — API อยู่ที่พอร์ต 5200
- ทดสอบเซิร์ฟเวอร์: `npm test`

## บัญชีผู้ใช้ (พอร์ตมาจาก WMS)

- สมัครสมาชิก → **รอแอดมินอนุมัติ** → ได้ออฟฟิศของตัวเองพร้อมทีมตัวอย่าง
- ลืมรหัสผ่าน → ลิงก์รีเซ็ตทางอีเมล (ใช้ได้ครั้งเดียว หมดอายุ 30 นาที)
- กติกาชื่อผู้ใช้/รหัสผ่าน, จำกัดการเดารหัส, 1 บัญชี = 1 อุปกรณ์
- หน้าตั้งค่า: รูปโปรไฟล์, ชื่อผู้ใช้, อีเมล, รหัสผ่าน, เสียงเกม, ภาษา, คีย์แหล่งข้อมูล (เข้ารหัสเก็บบนเซิร์ฟเวอร์)
- แอดมิน: อนุมัติ/ปฏิเสธ/ระงับ/คืนสิทธิ์/ลบผู้ใช้, กำหนดบทบาท

## ใช้งาน

- **คลิกกระดานบนผนัง** → กระดานงาน (Kanban 5 คอลัมน์ + โน้ต) ลากการ์ดย้ายคอลัมน์ได้ แยกแท็บ ส่วนตัว / ส่วนรวม
- **งานส่วนรวม** — ทุกคนในทีมเห็น แต่ละคนเพิ่มเอเจนต์ของตัวเองเข้าไปในลำดับงานได้ แต่ละขั้นทำในออฟฟิศของเจ้าของเอเจนต์ด้วย API key ของเจ้าของ
- **ลำดับการส่งต่อ (pipeline)** — เช่น นักวางแผน → นักออกแบบ → ผู้ตรวจงาน ผลลัพธ์ของขั้นก่อนถูกส่งให้ขั้นถัดไป
- **โน้ต** — ส่งถึงเอเจนต์คนเดียวหรือทุกคน เอเจนต์เดินไปอ่านที่กระดานและนำไปใช้ในผลงาน
- **คลิกโต๊ะว่าง** → จ้างเอเจนต์ใหม่ · **คลิกเอเจนต์** → โปรไฟล์ งานปัจจุบัน คิวงาน

## AI จริง

- หน้า **ตั้งค่า AI** (ปุ่มบนแถบบน / กดป้ายสถานะ AI): ใส่ API key ของตัวเอง (เข้ารหัสเก็บบนเซิร์ฟเวอร์) → ระบบทดสอบและดึงรายชื่อโมเดลจริงจากผู้ให้บริการมาให้ติ๊กเพิ่ม ไม่ต้องพิมพ์ API model ID เอง
- **Ollama**: ตรวจหาโมเดลที่ติดตั้งในเครื่องอัตโนมัติ และตั้งความยาว context ต่อโมเดลได้ (ค่าเริ่มต้น 8K)
- เอเจนต์ที่มีคีย์ของผู้ให้บริการของโมเดลตัวเองจะเรียกโมเดลจริง ตัวที่ไม่มีคีย์ยังทำงานแบบจำลอง — ป้ายมุมซ้ายบนบอกสถานะ (AI จริง / AI + จำลอง / โหมดจำลอง)
- ระหว่างที่โมเดลตอบ ข้อความจะไหลเข้ามาให้ดูสดในหน้ารายละเอียดงาน (ทุกคนที่เห็นงานนั้นดูได้)
- ถ้าเรียกไม่สำเร็จ งานจะขึ้น ⛔ พร้อมเหตุผล: ติด rate limit / ติดต่อไม่ได้ จะลองใหม่เอง (หน่วงเพิ่มขึ้นเรื่อยๆ สูงสุด 10 นาที) ส่วนคีย์ผิด เครดิตหมด หรือโมเดลปฏิเสธ ต้องกด “ลองใหม่”
- ในหน้าเดียวกัน: เปิด/ปิด AI จริง, งบต่อเดือน (ถึงงบแล้วเปลี่ยนเป็นจำลอง), สรุปค่าใช้จ่ายรายโมเดล (คำนวณจากราคาในคลังโมเดล)
- นักค้นคว้าและนักวิเคราะห์ข่าว (researcher / analyst) ค้นเว็บเองได้ถ้าผู้ให้บริการรองรับ

## บรรยากาศออฟฟิศ

- กลางคืน (หลัง 19:00 ตามเวลาเครื่อง) ห้องมืดลง โคมไฟโต๊ะเปิดเมื่อมีคนนั่ง ทีวีเรืองแสง เอเจนต์ยังทำงานต่อตามปกติ
- เอเจนต์ที่ว่างนานๆ จะเดินไปกดน้ำที่ตู้น้ำหรือรดน้ำต้นไม้ แล้วกลับโต๊ะ (หยุดทันทีเมื่อมีงาน)
- ไอคอนความรู้สึกเหนือหัว: ❤ งานเสร็จ, ? รอคำตอบ, หยดเหงื่อ งานติดปัญหา/ถูกส่งกลับ, ☕ พักกาแฟ
- มุมมอง isometric: พื้นไม้/กระเบื้อง ผนังสองด้าน โต๊ะมีลิ้นชักและโน้ตบุ๊กสีตามค่าย AI ชั้นหนังสือ ตู้เอกสาร เครื่องกาแฟ ตู้น้ำ ต้นไม้ · ตัวละคร 17×38 พิกเซล เดินได้ 4 ทิศตามแนวเฉียง นั่งหันตามโต๊ะ
- ไอคอน pixel art บนแถบบน หัวหน้าต่าง และสถานะงาน, เคอร์เซอร์ pixel
- **มือถือ / แท็บเล็ต**: ติดตั้งเป็นแอป (PWA) ได้ ใช้ในแนวนอน หน้าตาเหมือน laptop แบบกระชับ (แถบบนแถวเดียว หน้าต่างเต็มจอ) ถือแนวตั้งจะขึ้นหน้าให้หมุนเครื่อง · service worker เขียนเอง (`public/sw.js`) เก็บแค่ไฟล์ของแอป ไม่ cache ข้อมูลสด · ไอคอนสร้างด้วย `node scripts/make-icons.mjs`

## ทำงานร่วมกัน

- **เอเจนต์ถามกลับ** — ถ้าโจทย์ไม่ชัด เอเจนต์จะหยุดและโพสต์คำถาม (งานขึ้น ❓ บนกระดาน, ตัวเลขบนแท็บ, แจ้งเตือนเดสก์ท็อป) ใครที่เห็นงานก็ตอบได้ แล้วเอเจนต์ทำต่อโดยใช้คำตอบนั้น (โหมดจำลองจะถามบ้างแบบสุ่มกับงานที่รายละเอียดสั้น)
- **ผู้ตรวจงานส่งกลับเอง** — ผู้ตรวจงาน (reviewer) จบด้วยบรรทัด VERDICT ถ้าให้แก้ งานจะถูกส่งกลับไปยังขั้นที่ระบุพร้อมโน้ตความเห็นอัตโนมัติ สูงสุด 2 รอบต่องาน จากนั้นไปรอคนตรวจ
- **Model Arena** — กด ⚔️ ที่ขั้นที่มีผลงานแล้ว เลือก 2–4 โมเดลให้ทำขั้นนั้นใหม่เทียบกัน (ซ่อนชื่อได้) เลือกผู้ชนะและจะใช้เป็นผลงานของขั้นนั้นก็ได้ ผลการเลือกสะสมเป็นตารางคะแนน
- **สถิติ** (ปุ่ม 📊) — ผลงานรายเอเจนต์/โมเดล, เวลาเฉลี่ยต่อขั้น, อัตราผ่านรอบแรก, ค่าใช้จ่ายรายวัน 30 วัน, ตารางคะแนน Arena, ภาพรวมงานส่วนรวม และบรรยากาศข่าวของทุกรายการติดตาม

## ขยายออฟฟิศ

- **ผู้จัดการ (manager)** — งานใน “รอทำ” ที่ยังไม่ได้เลือกเอเจนต์ ผู้จัดการจะเดินมาอ่านโจทย์แล้ววางลำดับให้เอง (ใช้ AI จริงถ้ามีคีย์ ไม่มีก็ใช้แม่แบบตามคำในโจทย์)
- **ขั้นที่ทำพร้อมกัน** — ในหน้าสร้างงาน กด ⇉ ที่ขั้นใดให้ทำพร้อมกับขั้นข้างบน งานไปต่อเมื่อทั้งกลุ่มเสร็จ (ผลงานทั้งกลุ่มส่งให้ขั้นถัดไป)
- **หลายห้อง** — สูงสุด 4 ห้อง ห้องละ 8 โต๊ะ สลับด้วยแท็บเหนือออฟฟิศ (ดับเบิลคลิกเปลี่ยนชื่อ) ส่งงานข้ามห้องได้
- **ธีมออฟฟิศ** — ไม้อบอุ่น / โมเดิร์นสว่าง (ตั้งค่า → เสียงและภาษา)

## ข่าวและกระแสโซเชียล (Newsroom)

- **งานวิจัยข่าว** — ในหน้าสร้างงาน ติ๊ก “รวบรวมข่าวและข้อมูลโซเชียล” (หรือใช้แม่แบบ 📈 ข่าว/ความเห็น) ใส่หัวข้อ ชื่อหุ้น เหรียญ ภาษา และแหล่งข้อมูล — ขั้นของนักวิเคราะห์ (หรือขั้นแรก) จะเก็บข้อมูลก่อน แล้วเขียนรายงานพร้อมกราฟ
- **ห้องข่าว** (ปุ่ม 📺 หรือคลิกทีวีใต้นาฬิกา) — รายการติดตามแบบส่วนตัว/ส่วนรวม เลือกเอเจนต์ผู้ทำ และรอบการรัน (กดเอง / ทุก 6 ชม. / ทุกวัน / ทุกสัปดาห์ ตามเวลาเครื่องเซิร์ฟเวอร์) แต่ละรอบเอเจนต์จะเดินไปทำงานจริงบนฉาก เสร็จแล้วกลายเป็นรายงาน (เก็บ 30 ฉบับล่าสุด) พร้อมกราฟแนวโน้มความรู้สึก
- **แหล่งข้อมูล** — ไม่ต้องใช้คีย์: GDELT (รวมข่าวไทย), Google News RSS (ไทย/อังกฤษ), Hacker News, Crypto Fear & Greed, CoinGecko (ใส่คีย์ Demo ฟรีจะเสถียรกว่า) · ต้องใช้คีย์: Reddit, YouTube, Bluesky, Finnhub, Alpha Vantage · และให้โมเดลค้นเว็บเองเมื่อใช้ AI จริง
- ถ้าไม่มี API key ของโมเดล รายงานยังได้ข้อมูลจริง แต่ค่าความรู้สึกเป็นค่าประมาณจากรายการคำ (มีป้ายบอก)
- หมายเหตุ: Google อนุญาตให้ใช้ฟีด Google News เฉพาะการใช้งานส่วนตัวที่ไม่ใช่เชิงพาณิชย์ · GDELT จำกัด 1 คำขอ/5 วินาที (ระบบเว้นจังหวะให้แล้ว)

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `server/routes/auth.ts`, `users.ts` | ล็อกอิน สมัคร ลืมรหัสผ่าน โปรไฟล์ จัดการผู้ใช้ (จาก WMS) |
| `server/workspace/store.ts` | ข้อมูลออฟฟิศทุกคน (ในหน่วยความจำ + SQLite) และส่ง event แบบ real-time |
| `server/worker/engine.ts` | สมองของออฟฟิศ: เอเจนต์ตัดสินใจ หยิบงาน อ่านโน้ต ทำงาน ส่งต่อ |
| `server/sim/stage.ts` | บริบทของแต่ละขั้นงาน, `buildPrompt()` และผลลัพธ์จำลอง |
| `server/ai/*` | ตัวเชื่อมผู้ให้บริการ (Anthropic, OpenAI, Google, OpenRouter, Ollama) แบบ streaming + แปลง error + ดึงรายชื่อโมเดลที่คีย์ใช้ได้ |
| `server/usage.ts` | บันทึกโทเคนและค่าใช้จ่ายรายเดือนต่อคน |
| `server/research/*` | ตัวดึงข้อมูลแต่ละแหล่ง, รวมเป็นชุดข้อมูล, ประมาณความรู้สึก, prompt และอ่านผลจากโมเดล |
| `server/workspace/newsroom.ts` | รายการติดตาม ตารางเวลา และรายงาน |
| `server/sim/collab.ts`, `server/arena.ts`, `server/stats.ts` | ถามกลับ/ส่งกลับอัตโนมัติ, Model Arena, ตัวเลขหน้าสถิติ |
| `shared/pipeline.ts`, `server/sim/manager.ts` | กลุ่มขั้นที่ทำพร้อมกัน, การวางลำดับงานของผู้จัดการ |
| `src/components/charts.tsx`, `ResearchView.tsx` | กราฟ (SVG) และหน้ารายงาน |
| `src/components/AiSettingsWindow.tsx`, `KeyRow.tsx` | หน้าตั้งค่า AI: คีย์ ทดสอบ เลือกโมเดลจากรายชื่อจริง ตรวจหาโมเดล Ollama และ context |
| `server/keys.ts`, `crypto.ts` | API key ของผู้ใช้ เข้ารหัส AES-256-GCM |
| `src/sim/engine.ts` | ภาพเคลื่อนไหวในเบราว์เซอร์ (ตามสถานะที่เซิร์ฟเวอร์ส่งมา) ตำแหน่งเป็นช่องบนพื้น isometric |
| `src/scene/iso/*` | ฉาก isometric: เรขาคณิต (`geom`), วาดพิกเซลขอบคม (`pixels`), พื้นและผนัง (`room`), เฟอร์นิเจอร์, ผังโต๊ะและทางเดิน (`layout`), วาดทั้งฉากและหาสิ่งที่คลิก (`render`) |
| `src/scene/office.ts` | ของบนผนัง (กระดาน ทีวี โน้ต หน้าต่าง นาฬิกา) วาดแบบแบนแล้วเฉือนลงผนัง, ลูกโป่งคำพูด, ไอคอนอารมณ์, กลางคืน |
| `src/sprites/character.ts` | ตัวละคร 17×38 ประกอบจากชิ้นส่วน (ผม 9 แบบ เสื้อ 8 แบบ เครื่องประดับ 10 แบบ ตา 5 แบบ) มุมหน้า/เฉียง/หลัง |
| `shared/credentialPolicy.ts` | กติกาชื่อผู้ใช้/รหัสผ่าน (ใช้ทั้งหน้าเว็บและเซิร์ฟเวอร์) |

## Deploy

ทุกครั้งที่ push เข้า `main` GitHub Actions ([deploy.yml](.github/workflows/deploy.yml)) จะ build หน้าเว็บขึ้น GitHub Pages — ตั้งแต่เวอร์ชันนี้หน้าเว็บต้องต่อกับเซิร์ฟเวอร์ จึงยังพัฒนาอยู่บน branch `feat/v2-backend` และจะ merge เข้า `main` เมื่อตั้ง Cloudflare Tunnel เสร็จ

ใช้งานจริงบนเครื่องตัวเอง: `npm run build` แล้ว `npm start` — เซิร์ฟเวอร์เสิร์ฟทั้งหน้าเว็บและ API ที่ http://localhost:5200 (ชี้ Cloudflare Tunnel มาที่พอร์ตนี้ได้)
