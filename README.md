# Pixel Agent Office

ออฟฟิศ pixel art สำหรับทีม AI agents: จ้างเอเจนต์ แต่งตัวละคร เลือกโมเดลให้เหมาะกับหน้าที่ มอบหมายงานแบบส่งต่อกันเป็นทอดๆ และแปะโน้ตบนกระดานเพื่อสื่อสารกับเอเจนต์

🌐 **เล่นออนไลน์:** https://marburg4542.github.io/pixel-agent-office/

> **เฟส 1 = โหมดจำลอง** — ความคืบหน้าและผลลัพธ์ยังเป็นการจำลอง ยังไม่ได้เรียก API ของโมเดลจริง

## วิธีรัน

```bash
npm install
npm run dev
```

เปิด http://localhost:5173 — ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์ (ปุ่ม ↺ บนแถบด้านบนใช้รีเซ็ตกลับเป็นทีมตัวอย่าง)

## ใช้งาน

- **คลิกกระดานบนผนัง** → เปิดกระดานงาน (Kanban 5 คอลัมน์ + โน้ต) ลากการ์ดย้ายคอลัมน์ได้
  - `คลังงาน` = พักไว้ · `รอทำ` = เอเจนต์จะเดินมาหยิบ · `กำลังทำ` · `รอตรวจ` = รอคุณอนุมัติ/ขอให้แก้ · `เสร็จแล้ว`
- **ลำดับการส่งต่อ (pipeline)** — งานหนึ่งมีได้หลายขั้น เช่น นักวางแผน → นักออกแบบ → ผู้ตรวจงาน ผลลัพธ์ของขั้นก่อนจะถูกส่งให้ขั้นถัดไป
- **โน้ต** — ส่งถึงเอเจนต์คนเดียวหรือทุกคน ผูกกับงานได้ เอเจนต์จะเดินไปอ่านที่กระดาน (หรืออ่านระหว่างทำงาน) และนำไปใช้ในผลงาน
- **คลิกโต๊ะว่าง** → จ้างเอเจนต์ใหม่ (สร้างตัวละคร + เลือกหน้าที่/โมเดล) · **คลิกเอเจนต์** → ดูโปรไฟล์ งานปัจจุบัน คิวงาน
- **คลังโมเดล** — แก้ชื่อ, API model ID, ความเร็ว/คุณภาพ (ใช้ในการจำลอง) และราคา หรือเพิ่มโมเดลเองได้

## Deploy

ทุกครั้งที่ push เข้า `main` GitHub Actions ([deploy.yml](.github/workflows/deploy.yml)) จะ build แล้ว deploy ขึ้น GitHub Pages ให้อัตโนมัติ

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `src/store.ts` | state หลัก (zustand + persist) และ action ทั้งหมด |
| `src/sim/engine.ts` | เครื่องจำลอง: การเดิน อ่านกระดาน ทำงาน ส่งต่องาน |
| `src/sim/stage.ts` | บริบทของแต่ละขั้นงาน, `buildPrompt()` และผลลัพธ์จำลอง |
| `src/sprites/character.ts` | ตัวละคร 16×26 ประกอบจากชิ้นส่วน (ผม ตา ชุด เครื่องประดับ) |
| `src/scene/*` | ฉากออฟฟิศ วาดด้วย canvas และ hit-testing |
| `src/components/*` | UI: กระดานงาน, ตัวสร้างตัวละคร, หน้าต่างต่างๆ |
| `src/data/models.ts` | รายการโมเดลเริ่มต้น (Anthropic / OpenAI / Google / OpenRouter / Ollama) |

## เฟสถัดไป: เชื่อมต่อ API จริง

จุดที่เตรียมไว้: `buildStageContext()` + `buildPrompt()` ใน `src/sim/stage.ts` ประกอบ system prompt (คำสั่งประจำตัวเอเจนต์), โจทย์, ผลงานจากขั้นก่อน และโน้ตที่อ่านแล้ว — เฟสถัดไปจะแทนที่ `simulateOutput()` ด้วยการเรียกโมเดลจริงผ่าน backend เล็กๆ ที่เก็บ API key
